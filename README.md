# LU BIN Portfolio

[GitHub Pages](https://lubin010319.github.io/) · [版画・ビジュアル作品集 (29P)](https://lubin010319.github.io/art/)

面向二次元 AI 图像生成与漫画数据团队的个人作品集主页，支持 **日本語 / 简体中文 / English** 一键切换（首次访问自动匹配浏览器语言），纯静态 HTML / CSS / Vanilla JS 构建，无需打包即可部署。

```sh
python -m http.server 8080 --bind 127.0.0.1
```

## 收录项目

- [anime-char-rag-pipeline](https://github.com/lubin010319/anime-char-rag-pipeline) — 二次元角色合规采集、pHash 去重、WD14 属性提纯与 SigLIP 2 + Faiss 重排检索
- [manga-eval-benchmark](https://github.com/lubin010319/manga-eval-benchmark) — 日语漫画分镜/气泡检测、Manga OCR 评测、日中双语规范与 Label Studio 配置
- [lora-data-curation-exp](https://github.com/lubin010319/lora-data-curation-exp) — LoRA 6 类脏数据拦截、SDXL 长宽比分桶与固定 Seed A/B 盲评管线

`assets/results.json` 与 `assets/` 图版均来自各仓库实测产物；图版署名与许可见 [ATTRIBUTION.md](assets/ATTRIBUTION.md)。
